# Clinexa Medical System

**Clinexa** is a comprehensive web-based healthcare management system designed to streamline the interaction between healthcare providers and patients. It replaces traditional paper-based processes with a digital solution, improving efficiency and accessibility.

## Features

- **For Patients**: Secure signup/login, dashboard for appointments, doctor search, booking, medical history, and doctor feedback.
- **For Doctors**: Profile management, schedule management, patient records, and reports.

## Setup and Running Instructions

Follow these steps to set up and run the Clinexa application:

### Prerequisites
- Python 3.x
- pip (Python package installer)

### Installation

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/r4g4b/Clinexa
    cd Clinexa
    ```

2.  **Install Dependencies**:
    The project relies on Flask. Install it using pip:
    ```bash
    pip install flask
    ```

### Running the Application

1.  **Navigate to the source directory**:
    The main application file `app.py` is located in the `src` folder.
    ```bash
    cd src
    ```

2.  **Start the Server**:
    ```bash
    python3 app.py
    ```

3.  **Access the Application**:
    Open your web browser and navigate to:
    [http://localhost:5000](http://localhost:5000)
