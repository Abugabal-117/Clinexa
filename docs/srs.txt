1

Introduction

1.1

Purpose

Fall 2025

This Software Requirements Specification (SRS) document defines the functional and
non-functional requirements for Clinexa, a smart healthcare platform that facilitates
communication and management between doctors and patients. This document provides a detailed description of the system’s features, user interactions, and operational
constraints. It serves as a reference for the development team, stakeholders, and testers
throughout the software development life cycle

1.2

Scope

Clinexa is a web-based healthcare management system designed to improve the efficiency
and accessibility of medical services. The platform allows patients to book appointments,
communicate with doctors, and access their medical records. Doctors can also manage
patient data and schedule consultations.
The system aims to:
• Enhance communication between doctors and patients.
• Simplify appointment scheduling and medical record management.
• Reduce administrative overhead in healthcare services.

1.3

Definitions

• SRS: Software Requirements Specification.
• UI: User Interface.
• UX: User Experience.
• CMS: Clinexa Management System.
• Clinexa: The proposed smart healthcare management system.
• Patient: The end user who uses the system to book appointments and access
healthcare services.

Overview

This document outlines the purpose, scope, and functionality of the Clinexa system.
Subsequent sections will describe:

the system will deliver.

System Overview

2.1

Platform Perspective

The CMS replaces manual paper-based systems with a digital solution (web application)
to reduce errors, save time, and improve coordination between doctors and patients.

2.2

Application Functions

• User login and role-based access
• Manage doctor and patient profiles
• Schedule, reschedule, cancel appointments
• Search patients and appointments

User Classes

Different types of users who will interact with the system:

• The platform should maintain 99.9% uptime.
• Recovery time after a system failure should be within 5 minutes.
3.4.2

Maintainability

• The success rate of the maintenance will be 90%
• The maintenance speed will be 95%.

3.5

External Interface Requirements

3.5.1

User Interface

Fall 2025

Clinexa will provide a responsive web-based interface accessible from any browser (Google
Chrome, Firefox).
The interface will include login pages, dashboards for doctors and patients, appointment scheduling screens, and show reports
Patients will have access to booking and show reports, while doctors will have access
to patient lists, schedules and reports.
3.5.2

Hardware Interface

The system will run on standard computing devices, such as desktops, laptops, and
tablets.
No special hardware is required, except a device with a stable internet connection and
web browser.
3.5.3

Software Interface

The system will run on standard computing devices, such as desktops, laptops, and
tablets.
No special hardware is required, except a device with a stable internet connection and
web browser.
• Operating System: Any OS capable of running modern web browsers (Windows,
macOS, Linux).
• Backend Framework: Flask.
• Frontend: HTML, CSS.
• Database: File System
3.5.4

Communication Interface

Clinexa will use HTTP/HTTPS protocols for client–server communication to ensure security and reliability.
